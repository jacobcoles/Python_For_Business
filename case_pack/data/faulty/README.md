# Variant input sets

Each folder is a set of monthly inputs for one reporting period, as received, plus the prior
period so the movement check can run. They look like ordinary month-end deliveries.

Use them to practise the control set. Work from the evidence: run the checks, read the
exceptions, and decide the release status. Some release with a warning, and some must be
blocked. There is no F09 set.

The answers are deliberately not in this folder.
