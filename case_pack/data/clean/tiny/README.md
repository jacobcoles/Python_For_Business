# Tiny example: Northbridge unit N01, December 2025

Eight exported lines, small enough to check by hand.

Scope: **N01 only**. `expected_files.csv` in this folder lists one file, because one file
is all this example expects. Do not apply the three-unit completeness expectation here.

One line is `cancelled`. One cost line is a **positive** amount: a reversal, not a
mistake. `account_code` values keep their leading zero and are text, not numbers.

Task: calculate the posted operating result for N01 in December 2025, and the favourable
variance against `budget.csv`.
