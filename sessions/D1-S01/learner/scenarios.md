# Three scenarios: which tool would you recommend?

For each scenario, agree with your partner which tool you would recommend and the deciding factor.
There is more than one defensible answer. A reason about maintenance, data access or handover is stronger than
"I prefer it".

## Scenario A: The monthly sales summary
A team lead downloads one sales table each month into a workbook they already use, and needs
revenue by region for a meeting. It takes her ten minutes. Nobody else runs it.

## Scenario B: Twelve regional exports and a sign-off
Twelve regional offices each send a CSV export monthly. Before the figures go to the finance
director, someone must confirm every region arrived, no transaction is duplicated, every account
is mapped, and totals agree with each office's own control figure. The result goes into a
formatted pack with a note of what was checked. A colleague must be able to run it when the
analyst is on holiday.

## Scenario C: A dashboard that needs one extra calculation
A Power BI report already used by managers needs a simple next-quarter baseline added. The BI team
maintains the report and refreshes it in the Power BI service. The analyst who would write the
calculation knows Python; the BI team does not.
